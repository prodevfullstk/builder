# Prototype: Rapid UI & Logic Exploration

Build fast, functional prototypes that immediately answer user questions and demonstrate concepts.

## 1. UI Exploration
- Create interactive, visually stunning UI mockups with realistic mock data.
- Surface all primary actions (buttons, modals, drawers, tabs, filters) with real React state.
- Include responsive layouts (mobile, tablet, desktop) using Tailwind CSS.

## 2. Logic Exploration
- When demonstrating state machines (e.g. trading simulator calculations, checkout flows, multi-step wizards), make the state visible.
- Add feedback badges or status indicators so the user can see state changes in real time.

## 3. Zero Boilerplate Drag
- Use in-memory state or localStorage for rapid client-side prototyping before hooking up full backend storage.
- Provide sensible defaults and realistic sample data out of the box.
